# WADAH Network Scanner — النسخة الأولية

لوحة عربية RTL بواجهة داكنة بنفسجية، وخادم Python/Flask ومحرك فحص TCP محدود.

## ما الذي يعمل الآن؟
- واجهة لوحة تحكم متجاوبة للهاتف والكمبيوتر.
- فحص عنوان IPv4 خاص/محلي فقط، لمجموعة صغيرة ثابتة من المنافذ الشائعة.
- عرض المنافذ المفتوحة والمغلقة/غير المستجيبة.
- توصيات أمنية عامة مرتبطة ببعض المنافذ.
- تنزيل تقرير JSON، وتقرير PDF بعد تثبيت المكتبات.

## تشغيله على Windows
1. ثبّت Python 3.11 أو أحدث من الموقع الرسمي، وفعّل خيار Add Python to PATH أثناء التثبيت.
2. فك ضغط المجلد وافتح CMD داخله.
3. نفّذ:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
   ```
4. افتح `http://127.0.0.1:5000` في المتصفح.
5. أدخل عنوان جهاز خاص على شبكتك، مثل `192.168.1.1`، بعد التأكد من امتلاك الإذن.

## حدود مهمة
- هذه نسخة تأسيسية وليست ماسح ثغرات احترافياً. لا تقوم باستغلال الثغرات ولا تؤكد وجودها؛ هي فقط تختبر استجابة TCP على قائمة منافذ محددة.
- لا تفحص إلا أجهزة تملكها أو لديك تصريح صريح بفحصها.
- لا تنشر خادم التطوير مباشرة على الإنترنت. قبل النشر نحتاج إعداد نشر إنتاجي، مصادقة، تحديد معدل الطلبات، حماية من SSRF، تخزين آمن، وسجل تدقيق.
- تقرير PDF يستخدم خطوط ReportLab الافتراضية وقد لا يشكّل العربية بشكل مثالي؛ تصدير JSON متاح دائماً. يمكن إضافة خط عربي وتنسيق RTL في خطوة لاحقة.
- استضافة الموقع وحدها لا تسمح له بفحص شبكة منزلك. الفحص المحلي يعمل من الجهاز الذي يشغّل Python. سنفصل لاحقاً بين واجهة مستضافة ومحرك فحص محلي آمن إذا احتجنا ذلك.
